# Attendance Reporting Structure
these reports MUST BE the basic reports. You can add more insightful reports, just document everyhting what it is for and how is that reports derived.

## Final Required Set (Concise)

This section is the filtered must-have report scope per module.
The full matrix below remains as reference and optional expansion pool.

### Student: Required Reports

| Module | General Type of Report | Specific Type of Report | Purpose or Description |
|------|------|------|------|
| Student | Personal Attendance Records | Daily Attendance per Subject | Tracks session-level attendance behavior for selected date and enrolled subjects. |
| Student | Personal Attendance Records | Weekly Attendance Summary | Summarizes weekly present/absent/late behavior to improve accountability. |
| Student | Personal Attendance Records | Monthly Attendance Trends | Shows month-level trend direction for attendance behavior. |
| Student | Personal Attendance Records | Semestral Report (Per Subject / All Subjects) | Gives cumulative attendance performance for semester-level monitoring. |
| Student | Personal Attendance Records | Personal Late Arrival Report | Tracks frequency of late arrivals for punctuality management. |
| Student | Personal Attendance Records | Break Duration Log | Tracks break-out and break-in behavior, including extended breaks. |
| Student | Personal Attendance Records | Absent Logs | Lists conducted sessions where the student was absent. |
| Student | Personal Attendance Records | Personal Consistency Index | Composite attendance-punctuality stability metric with explainable insights. |

### Faculty: Required Reports

| Module | General Type of Report | Specific Type of Report | Purpose or Description |
|------|------|------|------|
| Faculty | Personal Attendance Records | Daily Attendance per Subject | Tracks personal attendance activity across assigned subjects. |
| Faculty | Personal Attendance Records | Weekly Attendance Summary | Summarizes personal weekly attendance consistency. |
| Faculty | Personal Attendance Records | Monthly Attendance Trends | Shows personal monthly attendance and punctuality behavior trend. |
| Faculty | Personal Attendance Records | Semestral Report | Cumulative personal attendance view for semester decisions. |
| Faculty | Personal Attendance Records | Personal Late Arrival Report (Instructor Start Delay) | Tracks recurring instructor lateness events. |
| Faculty | Personal Attendance Records | Personal Consistency Index | Stability metric for attendance and punctuality behavior. |
| Faculty | Class-Specific Reports | Daily Attendance per Subject | Session-level per-class monitoring of student attendance states. |
| Faculty | Class-Specific Reports | Monthly Attendance Trends | Identifies class trend shifts over the month. |
| Faculty | Class-Specific Reports | Semestral Report (Per Subject) | Semester accumulation for class-level participation and grading support. |
| Faculty | Class-Specific Reports | Absence Summaries per Section | Quantifies class absences for intervention and grading context. |
| Faculty | Class-Specific Reports | Late Arrival Report | Captures students with late entries in class windows. |
| Faculty | Class-Specific Reports | Break Duration Analysis | Detects long breaks/no-return behavior and break misuse patterns. |
| Faculty | Class-Specific Reports | Early Exits Report | Highlights exits before expected class completion. |
| Faculty | Class-Specific Reports | Punctuality Index per Section | Ranks students by arrival behavior against class start time. |
| Faculty | Class-Specific Reports | Class Participation Consistency Insight through Attendance | Provides class-level consistency scoring for participation risk analysis. |
