# Attendance Reporting Structure

| Module | General Type of Report | Specific Type of Report | Purpose or Description |
|------|------|------|------|

## Student Module

| Module | General Type of Report | Specific Type of Report | Purpose or Description |
|------|------|------|------|
| Student | Personal Attendance Records | Daily Attendance per Subject | Tracks presence, lateness, and breaks for each class session. |
| Student | Personal Attendance Records | Weekly Attendance Summary | Summarizes present/absent/late counts; promotes accountability. |
| Student | Personal Attendance Records | Monthly Attendance Trends | Visual trend of improvement or decline; encourages reflection. |
| Student | Personal Attendance Records | Semestral Report (Per Subject) | Provides cumulative data per subject for academic reference. |
| Student | Personal Attendance Records | Overall Semestral Summary | Consolidates all subjects for holistic engagement assessment. |
| Student | Personal Attendance Records | Attendance History Log (30 Days) | Maintains recent timestamps; balances data retention and privacy. |
| Student | Personal Attendance Records | Personal Late Arrival Report | Monitors frequency and duration of lateness for punctuality. |
| Student | Personal Attendance Records | Break Duration Log | Shows total break time to encourage responsible behavior. |
| Student | Personal Attendance Records | Personal Consistency Index | AI-generated metric predicting absence trends based on attendance regularity. |
